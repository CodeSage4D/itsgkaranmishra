4. Network & Security Architecture Note:
   - Client Public IP, City, Country, Referrer, and Device telemetry are captured.
   - NOTE ON MAC ADDRESSES:
     Under global W3C web standards and OS network security models, modern web 
     browsers (Chrome, Safari, Firefox, Edge) operate in a strict security sandbox.
     MAC (Media Access Control) addresses operate on OSI Layer 2 (Data Link layer) 
     and are deliberately hidden by all web browsers to prevent hardware fingerprinting.
     Public IP, location, device OS, and session telemetry provide the industry-standard 
     visitor identification.
